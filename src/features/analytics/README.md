# Analytics

Analytics reuses the summary aggregation used by the dashboard but lets the user choose a date range and inspect daily expenses for a selected month. It also includes a separate, interactive area/line chart for comparing three selected months; its legend can hide or show individual series. Tabs may navigate to related routes when the view is better represented by transactions or another feature.

Date range state is kept local to the page until the user applies the filter. The page uses responsive date-picker behavior so compact layouts remain usable on mobile.
